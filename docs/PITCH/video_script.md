# Three-minute demo video

Two phones on a table, a tray of onions, the printed mat. Phone A is the officer's; phone B belongs to the farmer. Record the screens with a second camera or screen capture. Timings are targets.

| Time | On screen | Voice |
|---|---|---|
| 0:00 | Phone A: swipe down, airplane mode on. Tap the Parakh icon. | "This is a procurement centre with no signal. Everything you'll see runs on the phone." |
| 0:10 | New lot. Farmer types 4821, officer types 1177, tap Draw sacks. | "Neither the farmer nor the officer picks which sacks get opened. Their two codes decide, and anyone can recompute the draw later." |
| 0:25 | Camera over tray 1. Gate bars turn green one by one; one refusal message ("Glare on the onions...") then the auto-shutter. | "The camera refuses bad photos and says why in one sentence. When every check passes, it takes the picture itself." |
| 0:40 | "Shake, look again". Second photo. Finish and grade. | "We shake the tray and look again, because the bottom of an onion hides rot. The second look is never counted as new onions." |
| 0:55 | Result screen: decision, procurable share by weight with interval, grade mix, sampling advice. | "The verdict comes with an interval, by weight, because procurement is settled by weight. And it tells the officer whether to stop or sample one more tray." |
| 1:10 | Tap a red bulb. Mask overlay, "Blackening 34.2%, above the 30% limit", the code underneath. | "Every rejected onion has a reason you can see and a code a machine can check." |
| 1:25 | Officer changes one bulb (reason: re-inspected by hand). Farmer contests another. Human actions list. Sign new revision. | "The officer can overrule the app, and the farmer can contest. Neither overwrites the original. Both are signed into a new revision." |
| 1:45 | Receipt with QR. Phone B (also in airplane mode) scans it. Six green checks. | "The farmer's phone checks the signature and re-runs the whole grading itself. Same answer, no internet, no need to trust us." |
| 2:05 | On phone B paste a code with one character changed: red "does not check out". | "Change one character and it fails. Tamper-evident, not tamper-proof: we say exactly what it proves." |
| 2:15 | Rule packs screen: time travel table, five packs, different "bought" column. | "Norms changed twice this year. The same stored measurements re-grade under any rulebook in one tap." |
| 2:30 | Fleet dashboard. | "Across centres, the dashboard shows who overrides the model often and whose measurements drift." |
| 2:40 | Slide: evaluation table from docs/EVALUATION.md, limitations beside it. | "Here is what we have measured so far, and what we have not. An instrument, a rulebook, a receipt: Parakh." |
